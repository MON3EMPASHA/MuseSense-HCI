# MuseSense Evaluation Protocol

## Goal
Check whether the current MuseSense interaction loop is understandable and usable.

## Test tasks
1. Start the app and complete login or guest entry.
2. Trigger a gesture action.
3. Observe YOLO object tracking feedback.
4. Observe expression/gaze adaptive feedback.
5. Review the current recommendation or context action.

## Metrics
- Task success/failure
- Time per task
- Number of recognition errors
- Whether feedback is understandable
- Participant comments

## Sample
- Target participants: 8 to 15

## Outputs
- Short results summary
- Table of task outcomes
- Feedback bullets
